# Power BI Waterfall Visualization

A demonstration of a beginning-to-ending waterfall calculation with DAX-style transformations and visual examples.

## Contents
- `PowerBi Code` — logic used in the example
- `Create Tables.PNG` — setup illustration
- `FINAL RESULT.png` — visualization output

## Approach
Use intermediate tables and conditional measures to represent opening balance, categorized changes, and closing balance. The example is designed to avoid distributing private business reports.
